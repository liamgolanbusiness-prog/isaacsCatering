# אייזיקיס קייטרינג · Isaacs Catering Ashdod

Mobile-first, Hebrew RTL marketing site for אייזיקיס קייטרינג (Ashdod, Israel).

## Stack
Static HTML, CSS, vanilla JS — no build step. Open `index.html` to preview.

## Features
- Hebrew RTL, mobile-first, responsive (320 → 1440+)
- Animated hero with 3D plate stack + parallax orbs
- IntersectionObserver scroll reveals + 3D tilt service cards
- Marquee strip, hover-flip cards, animated FAQ
- Floating WhatsApp button (bottom-right) with pulse
- Accessibility: skip-link, focus-visible, ARIA, reduced-motion support
- SEO: OpenGraph, Twitter cards, JSON-LD `FoodEstablishment`, robots.txt, sitemap.xml, manifest
